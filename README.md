One image summing up world news of Tuesday, 17 November 2026: an original
newspaper front page — "THE WORLD TODAY" — with 38 verified stories across
six continents. Ukraine drops the Kerch Bridge; Iran fires on a U.S. radar
in Bahrain; the Quad strikes critical-minerals deals in Manila; plus the
Dow's 849-point drop, Nvidia's record quarter, measles-free status lost,
Ebola past 11,000 cases, France's strike, Cyclone Akvan, AFCON qualifiers
and Mongolia's president resigning — with a world map of where it happened
and an "also on Tuesday" list. All stories verified against reporting of
17 November 2026; illustrations rendered for this edition.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only) copies the pre-built front page
`entry.png` into the output directory. The page itself is drawn by
`build_page.py` (PIL) from the photos in `assets/`.
